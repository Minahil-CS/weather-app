---

## 🚀 Pro Features

- **🌐 Live Global Geocoding & Autocomplete**: Instant search across world cities with auto-detection of user location via browser GPS coordinates.
- **📈 Interactive 24-Hour Forecast Engine**: Custom responsive HTML5 Canvas spline chart displaying hourly temperature curves, precipitation probability bars, and interactive hover tooltips.
- **🌬️ Advanced Atmospheric Telemetry**: Real-time diagnostic cards tracking:
  - **Wind Dynamics**: Directional compass dial, velocity, and gust tracking.
  - **Air Quality (AQI)**: PM2.5, PM10, and Ozone monitoring with health level indicators.
  - **Solar Arc & UV Index**: Semicircular daylight progress arc, sunrise/sunset countdowns, and UV risk levels.
  - **Moisture & Pressure**: Humidity percentages, dew point calculations, barometric pressure, and visibility metrics.
- **🌍 Persistent Global Watchlist**: Save and quickly toggle between favorite cities stored securely in browser `localStorage`.
- **🌡️ Unit Customization**: Seamless real-time conversion between Metric (`°C`, `km/h`) and Imperial (`°F`, `mph`) units.
- **🎨 Dynamic Ambient Theme**: Adaptive visual gradients and backdrop glows that morph based on day/night cycles and real-time weather states.

## 🛠️ Tech Stack & Tools

| Category | Technologies & Libraries Used |
| :--- | :--- |
| **Frontend Layout & Styling** | Semantic HTML5, Tailwind CSS (CDN), Custom CSS Animations & Glassmorphism |

| **State Management** | Browser `localStorage` API |

💻 Setup & Local Development
To run and test this project locally on your machine, follow these steps:

Clone the repository:
```
Bash
git clone [https://github.com/Minahil-CS/weather-app.git](https://github.com/Minahil-CS/weather-app.git)
```
Navigate to the directory:
```
Bash
cd weather-app
```
Run the application:

Open weather_app.html directly in any modern browser, or

Open the folder in VS Code and run it using the Live Server extension.
